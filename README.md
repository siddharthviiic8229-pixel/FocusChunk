# FocusChunk 🎯

FocusChunk is an Android App made to help users with ADHD break long text into short chunks to improve focus and retention.

<img width="300"  alt="Screenshot_20260925_110654" src="https://github.com/user-attachments/assets/4be06fc4-6b7b-460a-9442-44937d03c69b" />

#  Key Features

* **Chunked Reading View:** Displays content in structured segments to minimize distraction.
* **Resilient Offline Mode:** Gracefully handles network loss (Airplane mode, disabled Wi-Fi/Data) with clear user feedback and retry options.
* **Smooth UI:** Built with Jetpack Compose for seamless scrolling and responsive layout.

#  Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Architecture:** ViewModel, StateFlow, Coroutines
* **Build System:** Gradle

#  Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/siddharthviiic8229-pixel/FocusChunk.git
   ```

  2. Open the project in **Android Studio**.
